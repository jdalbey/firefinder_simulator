Yes. The easiest approach is to overlay a **Public Land Survey System (PLSS)** layer (township/range/section grid) on top of your Leaflet map.

A few options:

### 1. Use a PLSS tile service (simplest)

The U.S. Bureau of Land Management publishes PLSS data through ArcGIS services. You can add it as a dynamic map layer or tiled layer in Leaflet.

For example, using the ESRI Leaflet plugin:

```html
<script src="https://unpkg.com/esri-leaflet"></script>
```

```javascript
var plss = L.esri.dynamicMapLayer({
  url: 'https://gis.blm.gov/arcgis/rest/services/Cadastral/BLM_Natl_PLSS_CadNSDI/MapServer',
  opacity: 0.7
});

plss.addTo(map);
```

Depending on the service configuration, you may want to display only township/section layers.

---

### 2. Use PLSS vector data

If you need more control over styling and labels:

1. Download PLSS shapefiles or GeoJSON from BLM.
2. Convert to GeoJSON if necessary.
3. Add as a Leaflet GeoJSON layer:

```javascript
fetch('plss_sections.geojson')
  .then(r => r.json())
  .then(data => {
    L.geoJSON(data, {
      style: {
        color: '#ff0000',
        weight: 1,
        fill: false
      }
    }).addTo(map);
  });
```

This works well if you're only covering a state or county and want offline capability.

---

### 3. Use ArcGIS Feature Services directly

If you need interactive querying (e.g., click a section and get:

* Township: T30S
* Range: R10E
* Section: 14

), use an ArcGIS Feature Layer:

```javascript
var plssSections = L.esri.featureLayer({
  url: 'https://.../FeatureServer/0'
}).addTo(map);
```

Then attach popups from feature attributes.

---

### 4. Alternative datasets

Some states publish higher-quality PLSS layers than the federal dataset. For example:

* State GIS portals
* County assessor GIS services
* State natural resources agencies

These often have more accurate section boundaries and labels than the national BLM layer.

One thing to note: PLSS only exists in much of the western and central U.S. It generally does **not** cover the original colonies, Texas's independent survey systems, or other non-PLSS regions.

Here’s why:

---

### 1. OpenTopoMap is primarily derived from OpenStreetMap (OSM)

* Its basemap styling emphasizes:

  * Elevation contours
  * Topography shading
  * Water features
  * Trails, roads, cities
* Administrative boundaries exist, but only **major ones** (countries, states, counties, some protected areas)
* National forests may appear as green shading or labeled text if someone mapped it in OSM, but **not as authoritative boundaries**
* The dataset isn’t meant for legal or land-management purposes

---

* **USDA Forest Service**

  * Provides GIS layers for national forests
  * Format: shapefile, GeoJSON, feature service
  * Example: [FS GeoSpatial Data Gateway](https://data.fs.usda.gov/geodata/edw/datasets.php)

* **TIGER/USGS layers**

  * USGS/NPS may also provide protected lands datasets

* These layers show:

  * Exact polygon boundaries
  * Administrative labels
  * Useful for overlay on your Leaflet/OpenTopoMap tiles
